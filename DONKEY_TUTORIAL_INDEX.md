## 🎓 LEARNING TIPS

### **When You Get Stuck:**

1. **Read the error message** carefully
2. **Google the error** (someone else had it)
3. **Check you saved the file** (Ctrl+S)
4. **Restart the server** (Ctrl+C, then `npm run dev`)
5. **Check for typos** (especially in imports)

### **Common Mistakes:**

❌ Forgot `"use client"` at top (for interactive components)  
❌ Forgot `"use server"` at top (for server actions)  
❌ Forgot to save file  
❌ Typo in file path  
❌ Missing comma or bracket  
❌ Wrong import path  

### **Good Habits:**

✅ Save after each file (Ctrl+S)  
✅ Test after each section  
✅ Read explanations (don't just copy)  
✅ Type code yourself (builds memory)  
✅ Take breaks (15 min every hour)  
✅ Ask questions (Google is your friend)
