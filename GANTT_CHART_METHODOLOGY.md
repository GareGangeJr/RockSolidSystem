## 🧪 TESTING SCHEDULE

### **Unit Testing** (Ongoing during development)
- Each feature tested immediately after development
- Conducted by developers during Iterations 2-5

- All modules tested together
- Database interactions verified
- Data flow between modules confirmed

### **Functional Testing** (Week 21)
- All features tested against requirements
- Every use case verified
- Edge cases and error handling tested

- Management representative evaluation
- User experience feedback collected
